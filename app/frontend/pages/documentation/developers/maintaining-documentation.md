# Maintaining documentation

- Keep user instructions in `documentation/users/` and technical material in `documentation/developers/`.
- Give each document one audience and purpose. Move a document when its audience changes.
- Every directory of documents has an `index.md` with a tree of its documents.
- Add breadcrumbs to every document and link each breadcrumb level to its index page.
- Use the URL path segment as the text of every local documentation link.
- Use direct wording. Keep explanations only when they clarify an action, constraint, or decision.
- Update links when a document moves. Before publishing, verify that every local link resolves and every document renders.
