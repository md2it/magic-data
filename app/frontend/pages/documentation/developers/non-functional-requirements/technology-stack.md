# Technology stack

- **Backend:** Python 3.9+ and the standard library HTTP server.
- **Pages:** HTML and Markdown rendered by `markdown-it-py`.
- **Frontend:** static HTML, CSS, and JavaScript without a framework or build step.
- **Data:** local JSON files; no external database or server.
- **AI actions:** optional local Codex CLI or Claude CLI through [llm-engine](/documentation/developers/llm-engine).
