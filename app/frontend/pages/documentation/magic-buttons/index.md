# Magic buttons

## Overview

Magic buttons let you trigger an AI agent from the interface with a single click.

They make AI-assisted work available where it is needed, without requiring a person to open a terminal, compose a prompt, or transfer the result manually. A person selects a purposeful action and receives a result in the interface.
