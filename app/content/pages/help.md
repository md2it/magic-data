# Help

## What this application does

Magic-data lets you view and manage JSON datasets stored in the local `data` directory.

## Working with data

1. Select a dataset in the left panel.
2. The file contents appear in the main area.
3. Make changes to the JSON file using your usual editor.
4. Reload the page to see the updated contents.

## Stopping the application

Use the **Stop** button in the header. You can start the application again with the same launcher you used initially.
